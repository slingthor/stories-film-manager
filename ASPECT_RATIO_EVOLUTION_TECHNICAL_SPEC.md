## TECHNICAL IMPLEMENTATION NOTES

### **Transition Types:**
- **Smooth Transitions:** Use for returning to "normal" states (1.85:1 → 4:3, 1:1 → 4:3)
- **Snap Cuts:** Use for violence/trauma moments (4:3 → 1:1)
- **Explosive Expansion:** Use for liberation moment (4:3 → 2.39:1)

### **Framing During Transitions:**
- **Center Crop:** Maintain character positioning during all transitions
- **Preserve Eye Lines:** Ensure dialogue scenes remain coherent
- **Maintain Composition:** Key visual elements stay in frame during crops

### **VEO3 Considerations:**
- **Consistent Character Positioning:** Plates must work across all aspect ratios
- **Environmental Adaptation:** Baðstofa interior must function in all ratios
- **Camera Position Notes:** Include aspect ratio in all camera position descriptions
